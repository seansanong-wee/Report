วิธีแก้ error:
เกิดข้อผิดพลาดในการอัปโหลดไฟล์: Exception: รหัสไฟล์หรือโฟลเดอร์ไม่ถูกต้อง: ใส่_Folder_ID_ของท่านที่นี่

สาเหตุ:
Google Apps Script ที่ deploy อยู่ยังใช้ placeholder "ใส่_Folder_ID_ของท่านที่นี่"
ต้องแก้โค้ดฝั่ง Apps Script ไม่ใช่แก้หน้าเว็บอย่างเดียว

ขั้นตอนทำให้ใช้งานได้จริง:

1. เปิดโปรเจกต์ Google Apps Script เดิมที่ใช้สร้าง Web App URL นี้
   https://script.google.com/macros/s/AKfycbyPe_ep4Wmkj-V1ajfFmhZK4jUhD_LY1qMEPhhKHHDM44jX7T5fgTJge6WZXp0vbV5C7Q/exec

2. เปิดไฟล์ Code.gs ใน Apps Script Editor

3. ลบโค้ดเดิมทั้งหมด แล้วนำโค้ดจากไฟล์นี้ไปวางแทน:
   C:\Users\user\Desktop\ระบบ\Code.gs

4. กด Save

5. ไปที่ Deploy > Manage deployments

6. กดไอคอนดินสอเพื่อแก้ deployment เดิม

7. เลือก Version เป็น New version

8. ตรวจให้ถูกต้อง:
   - Execute as: Me
   - Who has access: Anyone

9. กด Deploy

10. ถ้า Google แสดง Web App URL ใหม่ ให้นำ URL ใหม่นั้นไปใส่ในช่อง
    "ตั้งค่า Google Apps Script (GAS)" บนหน้าเว็บ แล้วกด "บันทึก URL เชื่อมต่อ"

Folder ID ที่ตั้งไว้ใน Code.gs แล้ว:
16qGODaATJmWlSpXJy1kIvhtxz1OOc6NB

หลัง deploy สำเร็จ ไฟล์ที่ส่งจากหน้าเว็บจะถูกเก็บใน Google Drive โฟลเดอร์ "งานER"
และข้อมูลรายการส่งงานจะถูกบันทึกใน Google Sheet ชื่อ:
ER Selaphum Hospital Submissions

วิธีตรวจว่า deploy เป็น Code.gs เวอร์ชันล่าสุด:

1. เปิดลิงก์นี้
   https://script.google.com/macros/s/AKfycbyPe_ep4Wmkj-V1ajfFmhZK4jUhD_LY1qMEPhhKHHDM44jX7T5fgTJge6WZXp0vbV5C7Q/exec?action=version

2. ต้องเห็นข้อมูล JSON ที่มีคำว่า version และ actions

3. actions ต้องมี list, delete, updateStatus

ถ้ายังเห็นแค่ข้อความ:
ER Selaphum Hospital Submission API is running successfully.

แปลว่ายังไม่ได้เลือก New version ตอน Deploy หรือหน้าเว็บยังใช้ Web App URL คนละตัวกับที่ Deploy ล่าสุด
